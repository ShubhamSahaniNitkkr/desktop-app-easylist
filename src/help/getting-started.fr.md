# 🌟 Bienvenue sur EasyList

EasyList est un outil simple et puissant pour gérer les **Ingrédients**, créer des **Recettes**, planifier des **Menus Hebdomadaires**, et générer automatiquement des **Listes de Courses**.  
Ce guide explique chaque page, bouton et fonctionnalité de manière claire et facile.

---

En haut de l’application, vous trouverez :

- **Accueil**
- **Ingrédient**
- **Recette**
- **Menu**
- **Options**
- **Aide**
- **Sélecteur de langue (EN / FR)**

# 🥕 Page Ingrédient

Gérez tous vos ingrédients bruts.

## Actions possibles :

- Ajouter un ingrédient
- Modifier un ingrédient
- Supprimer un ingrédient
- Charger un ingrédient
- Importer via SQL

## Champs :

- Nom
- Fournisseur
- Numéro d’article
- Catégorie
- Unité
- Perte d’ingrédient (%)
- Perte de préparation (%)
- Perte de cuisson (%)
- Prix par kg
- Poids par pièce
- Poids par litre
- Allergènes
- Nutrition (Protéines, Glucides, Lipides, Calories)

## Boutons :

- Enregistrer
- Nouveau
- Charger
- Supprimer

---

# 🍳 Page Recette

Créez et gérez vos recettes.

## Actions possibles :

- Ajouter des ingrédients
- Ajouter des étapes
- Ajouter une image
- Ajouter un lien YouTube
- Ajuster la notation
- Mettre à l’échelle la recette
- Imprimer
- Sauvegarder comme ingrédient

## Boutons :

- Nouvelle Recette
- Ajouter Ingrédient
- Ajouter Étape
- Enregistrer
- Choisir Image
- Imprimer
- Utiliser comme Ingrédient

## Notation :

- 100 % = normal
- 50 % = moitié
- 150 % = une fois et demie
- Pas de limite

## Poids final :

Entrez un poids final → les ingrédients se mettent à l’échelle automatiquement.

# 📅 Page Menu

Planifiez vos repas pour la semaine.

## Vous pouvez :

- Ajouter des recettes par jour
- Ajouter des recettes par repas
- Enregistrer des menus
- Charger des menus
- Supprimer des menus
- Générer une liste de courses
- Imprimer le menu

## Liste de courses :

- Semaine entière
- Un seul jour
- Un seul repas

Prend en compte pertes, conversions, portions, rating, etc.
