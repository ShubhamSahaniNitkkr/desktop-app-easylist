# 🌟 Welcome to EasyList

EasyList is a simple and powerful tool to manage **Ingredients**, create **Recipes**, plan **Weekly Menus**, and generate **Shopping Lists** automatically.  
This guide explains every page, button, and feature in a clean and easy-to-follow way.

---

# 🧭 Navigation Overview

At the top of the app, you will find:

- **Home**
- **Ingredient**
- **Recipe**
- **Menu**
- **Options**
- **Help**
- **Language Selector (EN / FR)**

Each section is explained in detail below.

---

# 🏠 Home Page

The Home page is the starting dashboard.  
It contains shortcuts to quickly open:

- Ingredients
- Recipes
- Weekly Menus
- Options

This page is mainly for quick navigation.

# 🥕 Ingredient Page

This section is where you store and manage all your raw ingredients.

## What you can do here:

- Add new ingredients
- Edit existing ingredients
- Delete ingredients
- Load ingredient details into the form
- Import ingredients using SQL

## Fields you can fill:

- **Name** (e.g., Chicken, Milk, Rice)
- **Supplier** (Metro, Local Market, etc.)
- **Item Number** (Article code)
- **Category** (meat, vegetable, dairy, etc.)
- **Unit** (g, kg, ml, L, tsp, tbsp, piece, etc.)
- **Ingredient Loss (%)**
- **Preparation Loss (%)**
- **Cooking Loss (%)**
- **Price per kg**
- **Weight per piece**
- **Weight per liter**
- **Allergens**
- **Nutrition per 100g:**  
  Protein, Carbs, Fat, Calories

## Buttons available:

- **Save** – Save the ingredient
- **New** – Clear the form
- **Load** – Load data of a selected ingredient
- **Delete** – Remove the ingredient

# 🍳 Recipe Page

This is where you create dishes (recipes).

## What you can do here:

- Create new recipes
- Add ingredients to the recipe
- Adjust quantities
- Add cooking steps
- Add YouTube instructional links
- Upload an image
- Change rating (preference/portion multiplier)
- Scale recipe to a target weight
- Print the recipe
- Save recipe as an ingredient

## Buttons:

- **New Recipe** – Clear everything and start fresh
- **Add Ingredient** – Add a new ingredient row
- **Add Step** – Add a cooking step
- **Save** – Save your recipe
- **Pick Image** – Add a dish photo
- **Print** – Print or save as PDF
- **Use as Ingredient** – Save this recipe as a prepared ingredient

## Important features:

### ⭐ Rating (%)

Controls how much the recipe should be scaled.

- **100%** = normal recipe
- **50%** = half quantity
- **150%** = one and a half
- No upper limit

### ⭐ Target Output Weight

Enter a final weight (e.g., 1000g).  
EasyList will automatically adjust ingredient amounts to match the target weight.

# 📅 Weekly Menu Page

Use this page to plan your meals for the whole week.

## What you can do:

- Add recipes to each day
- Choose recipes for Breakfast, Lunch, Dinner, Snacks
- Save multiple weekly menus
- Load saved menus
- Delete menus
- Create shopping lists
- Print menus

## Buttons:

- **Save Menu** – Save your weekly plan
- **Load Menu** – Open a previously saved plan
- **Delete Menu** – Delete a menu
- **Shopping List** – Generate a full or partial list
- **Print** – Print a weekly menu

## Shopping List generation:

You can generate a shopping list for:

- An entire week
- A single day
- A single meal

Shopping list calculation includes:

- Ingredient losses
- Recipe scaling
- Unit conversion
- Recipe rating
- Number of people (Profiles)
